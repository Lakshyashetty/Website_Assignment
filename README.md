# Gym Website
## Power Fit Gym
### The PowerFit Gym Website is a modern and responsive fitness website designed to showcase gym services, trainers, and fitness programs. The website provides users with information about the gym, allows them to explore trainer profiles, calculate their BMI, and book gym classes. It features a visually appealing interface using modern UI techniques such as glassmorphism, animations, and interactive components to enhance user experience.

# 🛠️Technology
- *Html*
- *Css*
- *Bootstrap*
